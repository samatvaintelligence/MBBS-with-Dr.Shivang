## How to Export Slides as Images

### Option A: Browser Screenshot (quickest)
1. Open the HTML file in Chrome
2. Right-click on each slide → Inspect → select the `.slide` div
3. In DevTools, right-click the element → "Capture node screenshot"
4. Each saves as a 1080x1350 PNG — perfect for Instagram

### Option B: Using the export script
1. Open the HTML in Chrome at `http://localhost:8787/marketing/creatives/creative-1-neet-khatam.html`
2. Open DevTools Console (Cmd+Option+J)
3. Run: `document.querySelectorAll('.slide').forEach((s, i) => { /* use html2canvas or dom-to-image */ })`

### Option C: Canva Recreation
Use these HTML files as exact design specs. Match:
- Font: Poppins (available in Canva)
- Colors: #f39c12 (orange), #27ae60 (green), #e74c3c (red), #1a1a2e (dark bg)
- Dimensions: 1080 x 1350 px (Instagram portrait)
- Photos: from `public/assets/img/` folder
